# Maestro · AVI Music

Lanza las canciones de tu show desde el escenario con una tableta o un móvil, por wifi y sin internet.

**Descarga:** [avimusica.com/maestro](https://www.avimusica.com/maestro)

Este repositorio solo contiene las descargas oficiales (pestaña *Releases*):

| Sistema | Archivo |
|---|---|
| macOS (Intel y Apple Silicon) | `Maestro-Mac.zip` |
| Windows 10/11 | `Maestro-Windows.zip` |
| Android 8 o superior | `Maestro-Android.apk` |

El control funciona desde el navegador de cualquier móvil, tableta o iPad, sin instalar nada.
